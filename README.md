# FinanceTracker

FinanceTracker is a modern frontend-only financial tracking web app built with React. It helps users track stock and cryptocurrency holdings, view portfolio summaries, monitor returns, and manage assets directly in the browser.

## Features

- Track stocks and cryptocurrencies
- Separate Home, Summary, Stocks, and Crypto pages
- Real-time portfolio calculations
- Dashboard analytics
- Gold,Silver,Platinum and other rare earth metals
- Portfolio allocation and trend charts
- Search crypto assets using CoinGecko
- Track common US stocks and ETFs using Stooq public quote data
- Add, edit, and delete holdings
- Dark mode interface
- Responsive design
- Browser `localStorage` persistence
- No backend required

## Built With

- React
- Vite
- Tailwind CSS
- JavaScript
- Recharts
- Lucide React
- CoinGecko API
- Stooq public quote API
